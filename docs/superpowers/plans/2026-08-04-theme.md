# Theme Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give Switchboard eight accent colors and four canvases, plus the serif type and 4px shape scales that come with them, chosen from a menu in the header and remembered per browser.

**Architecture:** Three independent token layers — accent, canvas, status — declared as `[data-accent=…]` and `[data-canvas=…]` blocks in `web/style.css` and composed at render time by two attributes on `<html>`. Every color in `web/style.css` becomes a `var()` read; no rule holds a literal hex outside the token blocks. A Node test parses the stylesheet and checks every one of the thirty-two combinations for WCAG contrast, which is why every token value is a literal hex rather than a `color-mix()`.

**Tech Stack:** Vanilla CSS custom properties, vanilla ES modules, `node:test`. Two self-hosted variable woff2 files (EB Garamond, Inter). No new dependencies.

**Spec:** `docs/superpowers/specs/2026-08-03-theme-design.md`

## Global Constraints

- **Nine hexes differ from the spec's tables.** The spec's contrast test asserts only against `--canvas`, but on the light canvases `--surface` is *darker* than the canvas and is where card text actually sits. Checked against all four surface tokens, nine values fall between 4.0 and 4.49. The corrected values are in Task 1 and are the authority; the spec's tables are not. Corrected: coral `--accent-deep` `#a35333`→`#a15232`, amber `#936a25`→`#876122`, moss `#57742f`→`#54702d`, cream `--muted` `#6c6a64`→`#6a6862`, paper `--muted` `#6b6f79`→`#656872`, light `working` `#2f7d4f`→`#2c754a`, light `needs-you` `#9c5a0c`→`#99580c`, light `done` `#2b6cb0`→`#2a6aae`, light `stopped` `#6c6a64`→`#6a6862`.
- **`src/server.ts:948` stays an exact-match allowlist.** Never join a user-controlled path segment. The two font files sit flat in `web/` and are added as two more literal string entries.
- **Every color in `web/style.css` is a `var()` read outside the token blocks**, with exactly two documented exceptions named in Task 3: `#ffffff` on primary button labels (which is what `--accent-deep` is chosen against and what Task 1's test asserts), and the one `::selection` rgba that needs an alpha no token carries. Task 3 ends with a grep that enforces this and excludes only those two.
- **Defaults are Ink + Coral**, carried by static attributes on `<html>` so a browser with JS broken still gets a complete theme.
- **localStorage key is `switchboard.theme`**, value `{"accent":"coral","canvas":"ink"}`. Not `state.json`, not SSE.
- **`--bar-h: 3.476rem` (`web/style.css:12`) is measured, not assumed.** Task 5 changes `#bar`'s padding and font size, which invalidates it. It gets re-measured in a real browser and written back. Failure mode is a few pixels of overlap — nothing throws.
- Run the whole suite with `npm test`. Single file: `node --test test/palette.test.ts`.
- Commit style: lowercase `type: subject`, imperative, no scope. End every commit message with `Co-Authored-By: Claude Opus 5 <noreply@anthropic.com>`.

```ts
import { test } from 'node:test';
import assert from 'node:assert';
import { readFile } from 'node:fs/promises';

const css = await readFile(new URL('../web/style.css', import.meta.url), 'utf8');

/**
 * The custom properties declared inside one `[attr=value] { … }` rule. The
 * stylesheet is the single source of every hex in the palette — duplicating
 * the tables here would let the two drift and the test would still pass.
 */
function block(selector: string): Record<string, string> {
  const m = css.match(new RegExp(`\\[${selector}\\]\\s*\\{([^}]*)\\}`));
  assert.ok(m, `no rule for [${selector}] in web/style.css`);
  return Object.fromEntries(
    [...m[1].matchAll(/(--[\w-]+)\s*:\s*([^;]+);/g)].map(([, k, v]) => [k, v.trim()]),
  );
}

/** WCAG 2.x relative luminance of a `#rrggbb` string. */
function luminance(hex: string): number {
  const c = [1, 3, 5]
    .map((i) => parseInt(hex.slice(i, i + 2), 16) / 255)
    .map((v) => (v <= 0.03928 ? v / 12.92 : ((v + 0.055) / 1.055) ** 2.4));
  return 0.2126 * c[0] + 0.7152 * c[1] + 0.0722 * c[2];
}

function ratio(a: string, b: string): number {
  const [x, y] = [luminance(a), luminance(b)];
  return (Math.max(x, y) + 0.05) / (Math.min(x, y) + 0.05);
}

/** The canvas blocks alias two accent names rather than restating the hexes. */
const deref = (value: string, accent: Record<string, string>): string =>
  value.startsWith('var(') ? accent[value.slice(4, -1)] : value;

const ACCENTS = ['coral', 'amber', 'moss', 'teal', 'sky', 'indigo', 'violet', 'rose'];
const CANVASES = ['cream', 'paper', 'ink', 'void'];
// Every floor text can land on. On the light canvases --surface is *darker*
// than --canvas (cards sit down, menus float up), so checking --canvas alone
// checks the one surface almost no text is drawn on.
const SURFACES = ['--canvas', '--surface', '--surface-2', '--well'];

test('every accent stays legible on every canvas', () => {
  for (const a of ACCENTS) {
    const accent = block(`data-accent=${a}`);
    const white = ratio(accent['--accent-deep'], '#ffffff');
    assert.ok(white >= 4.5, `${a}: white button label on --accent-deep is ${white.toFixed(2)}`);
    for (const c of CANVASES) {
      const canvas = block(`data-canvas=${c}`);
      const text = deref(canvas['--accent-text'], accent);
      const line = deref(canvas['--accent-line'], accent);
      for (const s of SURFACES) {
        const t = ratio(text, canvas[s]);
        assert.ok(t >= 4.5, `${a} link on ${c} ${s} is ${t.toFixed(2)}`);
        const l = ratio(line, canvas[s]);
        assert.ok(l >= 3, `${a} ring on ${c} ${s} is ${l.toFixed(2)}`);
      }
    }
  }
});

test('every canvas keeps its own text and status colours legible', () => {
  const TEXT = ['--ink', '--body', '--muted', '--working', '--needs', '--done', '--stopped', '--error'];
  // .ref pills paint --canvas on a fill of the lane's colour (see .ref > span).
  const FILLS = ['--lane-a', '--lane-b', '--working', '--needs', '--done', '--stopped', '--error'];
  for (const c of CANVASES) {
    const canvas = block(`data-canvas=${c}`);
    for (const t of TEXT) {
      for (const s of SURFACES) {
        const r = ratio(canvas[t], canvas[s]);
        assert.ok(r >= 4.5, `${c}: ${t} on ${s} is ${r.toFixed(2)}`);
      }
    }
    for (const f of FILLS) {
      const r = ratio(canvas['--canvas'], canvas[f]);
      assert.ok(r >= 4.5, `${c}: ref pill label on ${f} is ${r.toFixed(2)}`);
    }
    for (const [fg, bg] of [['--needs', '--warn-bg'], ['--error', '--error-bg'], ['--body', '--hover']]) {
      const r = ratio(canvas[fg], canvas[bg]);
      assert.ok(r >= 4.5, `${c}: ${fg} on ${bg} is ${r.toFixed(2)}`);
    }
  }
});

// A color-mix() would collapse the accent table from 24 values to 8, but
// nothing in Node can resolve one, so every assertion above would silently
// have nothing to measure and this file would pass while the app was
// illegible. The 8-digit form is allowed for --shadow, which carries alpha and
// is not measured.
test('the palette is literal hexes, so this test has something to measure', () => {
  for (const a of ACCENTS) {
    for (const [k, v] of Object.entries(block(`data-accent=${a}`))) {
      assert.match(v, /^#[0-9a-f]{6}$/, `${a} ${k} is not a literal hex`);
    }
  }
  for (const c of CANVASES) {
    for (const [k, v] of Object.entries(block(`data-canvas=${c}`))) {
      assert.match(v, /^(#[0-9a-f]{6}|#[0-9a-f]{8}|var\(--accent-(deep|lift)\))$/, `${c} ${k} is not a literal hex`);
    }
  }
});
```

```js
// In picker order: eight accents around the wheel starting at coral, then the
// canvases light-to-dark. The hexes live in web/style.css, which is what
// test/palette.test.ts measures — these are only names.
export const ACCENTS = Object.freeze(['coral', 'amber', 'moss', 'teal', 'sky', 'indigo', 'violet', 'rose']);
export const CANVASES = Object.freeze(['cream', 'paper', 'ink', 'void']);

const DEFAULT_THEME = Object.freeze({ accent: 'coral', canvas: 'ink' });

/**
 * The stored theme, or the default for anything that is not a known pair.
 * localStorage is user-editable and this value is read before the stylesheet
 * applies, so an unvalidated one paints an unstyled page. The two halves fall
 * back independently: an unrecognised accent should not also throw away a
 * perfectly good canvas.
 */
export function readTheme(raw) {
  let stored;
  try {
    stored = JSON.parse(raw);
  } catch {
    return { ...DEFAULT_THEME };
  }
  return {
    accent: ACCENTS.includes(stored?.accent) ? stored.accent : DEFAULT_THEME.accent,
    canvas: CANVASES.includes(stored?.canvas) ? stored.canvas : DEFAULT_THEME.canvas,
  };
}
```

/**

 * accent's --accent from the stylesheet's token block. The hexes stay in one
 * place — a JS colour table here would be a second copy that the palette test
 * cannot see.
 */
function swatch(accent) {
  const dot = document.createElement('i');
  dot.className = 'swatch';
  dot.dataset.accent = accent;
  return dot;
}

/**
 * Deliberately not menuItem(): that one closes the menu, and here the feedback
 * is the whole page — trying a second canvas against the same accent should not
 * cost two clicks to reopen. Escape and any outside click still close it.
 */
function themeChoice(content, choose) {
  const b = document.createElement('button');
  b.type = 'button';
  b.onclick = (e) => { e.stopPropagation(); choose(); };
  b.append(content);
  return b;
}

function renderTheme() {
  const wrap = $('#theme-wrap');
  wrap.replaceChildren();

  const btn = document.createElement('button');
  btn.type = 'button';
  btn.className = `menu-btn${menuFor === 'theme' ? ' open' : ''}`;
  btn.title = 'Theme';
  btn.setAttribute('aria-label', 'Theme');
  btn.append(swatch(theme.accent));
  btn.onclick = (e) => {
    e.stopPropagation();
    menuFor = menuFor === 'theme' ? null : 'theme';
    render();
  };
  wrap.append(btn);
  if (menuFor !== 'theme') return;

  const menu = document.createElement('div');
  menu.className = 'menu';
  menu.onclick = (e) => e.stopPropagation();

  const row = document.createElement('div');
  row.className = 'swatch-row';
  for (const a of ACCENTS) {
    const b = themeChoice(swatch(a), () => setTheme({ accent: a }));
    b.className = `swatch-btn${theme.accent === a ? ' on' : ''}`;
    b.title = a;
    b.setAttribute('aria-label', a);
    b.setAttribute('aria-pressed', String(theme.accent === a));
    row.append(b);
  }
  menu.append(row);
  for (const c of CANVASES) {
    const b = themeChoice(CANVAS_LABEL[c], () => setTheme({ canvas: c }));
    b.className = theme.canvas === c ? 'on' : '';
    b.setAttribute('aria-pressed', String(theme.canvas === c));
    menu.append(b);
  }
  wrap.append(menu);
}

## Out of scope

Carried from the spec, restated so nobody adds them mid-task: a custom hex field, an Auto mode following `prefers-color-scheme`, per-canvas status tuning beyond the two sets, reassigning which graph lane gets which colour, syncing the theme across browsers, and per-session or per-account theming. The picker sets two attributes on `<html>` and that is the entire mechanism.
